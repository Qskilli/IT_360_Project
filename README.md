# Digital Forensics Law Assistant
 
## Project Overview
 
The Digital Forensics Law Assistant is a decision-support tool designed to assist digital forensic investigators in identifying potentially relevant state and federal laws based on a case description.
 
The application utilizes artificial intelligence to analyze investigator-provided case narratives, extract important facts, and match those facts against a curated legal database.
 
## Features
 
- AI-powered case analysis
- Automated fact extraction
- Federal and state law matching
- Legal citation display
- Evidence handling recommendations
- Investigation report generation
